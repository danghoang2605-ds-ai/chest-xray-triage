Summary

Task
Flag abnormal chest X-rays and localize 14 finding types on the public VinDr‑CXR dataset [1].
Idea
A cheap classifier screens every study; the expensive detector runs only on the studies it flags.
Safety rule
τ is the highest threshold that keeps sensitivity at 95% on validation, then reported once on an untouched test split.
Evaluation
Bootstrap CIs, calibration error, mAP@0.4 with and without the gate, latency, subgroups, an external test on NIH ChestX-ray14 and the operational cost of every miss.
Engineering
FastAPI with Grad-CAM, ONNX export, 54 tests without a GPU, an end-to-end smoke test, CI, Docker and a model card.

1Problem

Detectors that localize findings are the expensive part of a chest X-ray pipeline, especially at the resolution small lesions need. Yet most studies are normal.

~70%of VinDr‑CXR studies have no finding [1]. Running the detector on every one spends most of the compute where none is needed.

Skipping studies with a fast classifier is only acceptable if it almost never lets an abnormal study through. The question this project answers: how much time can a gate save, and what does it cost in missed findings?

2Method

StageModel and inputHow it is trained or set
GateResNet-50 [2], ImageNet weights, one output logit; 512 × 512BCE with pos_weight ≈ 2.4 for the 70/30 balance; rotations, shifts, zoom, brightness, no flips; AdamW, cosine schedule, mixed precision; best validation AUC kept
CalibrationTemperature scaling [3]: p = σ(z / T)T minimizes NLL on validation; τ is the highest threshold with validation sensitivity ≥ 0.95
DetectorYOLOv8s [4], COCO weights, 14 classes; 1024 × 1024Three radiologists' boxes fused with WBF [5] at IoU 0.4; 10% normal studies as background; no flips
ExplanationGrad-CAM [6] on the last ResNet block (2048 × 16 × 16)Shows which regions raised the gate score

5Evaluation protocol

Data
15,000 VinDr‑CXR training images, each read by 3 of 17 radiologists [1].
Split
80 / 10 / 10 train, validation, test at image level, stratified on the abnormal label, fixed seed.
Selection
Best epoch, T and τ are chosen on validation. Test is used once.
Gate metrics
AUC; sensitivity and specificity at τ; expected calibration error (15 bins) before and after scaling.
Detector metric
mAP at IoU 0.4 over 14 classes, Pascal VOC all-point interpolation, detector-only and two-stage.
Uncertainty
95% confidence intervals from 1,000 bootstrap resamples of test studies.
Subgroups
AUC, sensitivity, specificity by sex and by age band (<40, 40–59, 60+) from DICOM headers; groups under 30 studies or 10 abnormal are flagged.
Error analysis
Abnormal test studies the gate cleared, by finding class, with the lowest-scoring cases listed for review.
External validation
NIH ChestX-ray14 (US), frontal views, stratified sample; weights, T and τ reused without retuning. NIH labels are NLP-mined from reports with a different label set, so this tests transfer, not like-for-like accuracy.
Latency
Warm-up excluded, GPU synchronized before timing, images preloaded; mean, p50 and p95 per study.
Impact model
GPU time = mean latency × daily volume on one GPU; abnormal studies missed = volume × prevalence × (1 − sensitivity). At tens of milliseconds per study the GPU cost is small; the case for the gate is throughput on fixed, shared or CPU-only hardware, and the table makes that trade explicit rather than claiming savings.

8Reproduce

Python 3.10+ and a GPU for training (a free Kaggle T4 is enough). The whole run is also notebooks/kaggle_run.ipynb or make all; make quick (configs/quick.yaml) gives a first run in about 1–2 hours, and python scripts/smoke_test.py checks every stage on synthetic data in a few minutes.

git clone https://github.com/danghoang2605-ds-ai/chest-xray-triage.git && cd chest-xray-triage
pip install -r requirements.txt
python -m src.data             --config configs/default.yaml   # labels, WBF boxes, YOLO dataset
python -m src.train_classifier --config configs/default.yaml   # stage 1
python -m src.train_detector   --config configs/default.yaml   # stage 2
python -m src.evaluate         --config configs/default.yaml   # AUC + CIs, calibration, subgroups, mAP
python -m src.error_analysis   --config configs/default.yaml   # gate misses by finding class
python -m src.external_eval    --config configs/default.yaml   # optional: NIH ChestX-ray14
python -m src.benchmark        --config configs/default.yaml --half
python -m src.impact           --config configs/default.yaml   # compute time, cost, abnormal studies missed
python -m src.plots --config configs/default.yaml && python -m src.report   # figures, README, this page

9Limitations

Single-country data
VinDr‑CXR comes from Vietnamese hospitals. The NIH check measures transfer to one US source; it does not replace prospective validation, and its NLP-mined labels limit what it can show.
Label noise
Radiologists often disagree; the “any radiologist” rule trades noise for recall.
Small findings
AP for small lesions such as nodules is typically low.
Single point of failure
A study the gate clears is never read by the detector. Two-stage mAP measures this cost but does not remove it.
Explanations
Grad-CAM shows where the classifier attended, not that its reasoning is correct.
